# Landing page imobiliária

Exercício HTML/CSS com apresentação de empreendimento, mosaico de imagens e formulário visual de interesse.

## Tecnologias

- HTML
- CSS

## Funcionalidades e utilização

Percorra as seções e visualize o formulário; não há envio de mensagens implementado.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/leading-page-simples-.git
cd leading-page-simples-
python -m http.server 8000 --directory "leading page 01"
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
